# Code of conduct

- Be respectful. Disagree with ideas, not people.
- Assume good faith.
- Keep it about the project. No harassment, no personal attacks, no
  discrimination.
- Give credit, cite sources, and say when you are not sure.

Report unacceptable behaviour privately to the maintainer at the e-mail on
their GitHub profile. Reports are handled in confidence. Contributions that
break these rules may be edited, removed or locked, and repeat offenders
blocked.

Adapted from the Contributor Covenant, version 2.1.
