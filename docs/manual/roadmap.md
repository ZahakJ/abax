# Roadmap

- **Sound on Android**, through AAudio and the `ndk` crate.
- **Signed desktop builds**: a notarized macOS app and a signed Windows
  binary.
- **More multiplication and division**: decimals and Kojima's rules for
  placing the point, longer multipliers and divisors, head-first methods.
- **Translations.** Interface and lesson text live in `curriculum.rs` and
  the screens.
- **Dictated numbers** (*yomiage-zan*).
- **A placement probe.** The scheduler supports placing a learner from a
  short mixed test; there is no screen for it yet.
- **Faster flash steps.** The ladders stop at 0.4 s per number for one
  digit and 0.5 s for three.

Suggestions go in GitHub issues.
